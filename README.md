# Future Q Technologies

> **"We Don't Build Rote Memorizers. We Build Real Problem Solvers."**

Official company website and directory for **Future Q Technologies** — an Indian education-technology company founded by two brothers in a hostel room in Bokaro Steel City, Jharkhand.

Designed with a nostalgic, high-contrast **2004 "The Facebook"** inspired layout and simple system typography.

---

## 🚀 Live Products

- **[Focus Mode Player](https://focusmode.online)** (`focusmode.online`) — Distraction-free student productivity workspace for competitive exam aspirants (JEE, NEET, SSC). Eliminates algorithmic feeds, comments, and recommendations while providing curated study streams and Pomodoro tracking.
- **[CoachingWala](https://cwwala.vercel.app)** (`cwwala.vercel.app`) — Operating system and cloud ERP for offline coaching centers. Digital student enrollment, attendance tracking, and transparent fee ledgers tested door-to-door in local coaching hubs.

---

## 🛠️ Tech Stack

- **Frontend**: React 18, Vite 8, Tailwind CSS v4, Lucide React
- **Backend & Cloud**: Supabase, Firebase, PostgreSQL
- **Typography & Aesthetics**: 2004 The Facebook system styling (`Lucida Grande`, `Tahoma`, `Verdana`, `Arial`, `#3b5998`)
- **100% In-House Engineering**: Zero outsourced development

## 📦 Getting Started

```bash
# Clone the repository
git clone https://github.com/saurabhraj230125/agency.git

# Navigate into the project
cd agency

# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
